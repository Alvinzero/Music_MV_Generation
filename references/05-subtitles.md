# 第五步：字幕样式（按画面推导，不是挑预设）

**字幕是唯一一个"每部片都必须重新设计一次"的元素。** 分镜可以复用模板、转场可以复用曲线，
字幕不行——它是文字直接站在画面正中间和观众对视，样式一错，整条片子的质感就掉一个档。

所以这里不给你四个筐。这里给你**一套推导程序 + 十二套可执行的配方**：
先读画面的八个特征，再用配方库做一次匹配打分，取 top2 各排一句样张，让用户选。
**每部片最后都会得到一套只属于它的参数**，而不是"暗调就无卡暖光"。

> 十二套配方的具体参数在 `05b-subtitle-recipes.md`。
> 逐句落位、字号档、卡片像素级做法在 `05a-subtitle-layout.md`。

---

## 一、为什么"四族路由"是错的

曾经的写法是：暗调 → 无卡暖光；暖亮纸质 → 纸卡；实拍 → 底条；口播 → 硬剪。

它的问题不是分错了，是**分得太粗**：

- 所有暗调片都会得到同一套暖光字——夜景纸雕、悬疑实拍、赛博朋克、黑白史诗，长一个样
- 同一部片里，主歌和副歌的字幕没有任何区别，情绪上不去
- 反过来，明明气质完全不同的两支片，字幕却撞款，观众会觉得"这是同一个模板套的"

**判断标准很简单**：把你这套字幕的主色去掉，只看字形和排布，能不能认出是哪部片？
认不出，说明字幕没有属于这部片的特征。

## 二、字幕配方的七个维度

任何一套字幕样式，本质上是在这七个维度上各选一个值。**十二套配方就是十二组取值**，
你也可以在两个配方之间取中间值——只要七个维度都定得下来，参数就定得下来。

| # | 维度 | 常见取值 | 决定什么 |
|---|---|---|---|
| ① | **载体** | 无 / 纸卡 / 布条 / 胶带 / 标签 / 磨砂条 / 光带 / 镂空 | 字和画面的关系：贴上去，还是长在上面 |
| ② | **字形** | 宋 / 黑 / 圆 / 手写 / 碑 / 等宽 / 斜衬线 | 年代与文化语境 |
| ③ | **字色逻辑** | 暖墨 / 冷墨 / 暖米 / 背景反色 / 双色分离 / 单点强调 | 字是"印上去"还是"发出来" |
| ④ | **分离手段** | 描边 / 辉光 / 柔影 / 硬投影 / 底衬 / 无 | 亮处能不能读、暗处会不会脏 |
| ⑤ | **入场动效** | 逐字点亮 / 打字机 / 弹入 / 上浮 / 描边生长 / 硬切 / 遮罩跟随 | 节奏感；和音乐的咬合 |
| ⑥ | **排布** | 居中单行 / 底部中轴 / 竖排右置 / 双行阶梯 / 偏侧 / 逐词移位 | 视觉重心 |
| ⑦ | **与画面的关系** | 贴合载体 / 悬浮暗部 / 反色镂空 / 跟随主体 / 压边 | 观众信不信"这字本来就该在这" |

**七个维度定完，一套样式就唯一了。** 这也是为什么"暗调 → 无卡暖光"不够：
它只定了 ①②④，其余四个维度全靠默认值，所有片自然撞款。

## 三、推导程序：八个画面特征 → 十二套配方

### 第一步：读这八个特征（每个 1–3 秒就能判断）

| 特征 | 怎么读 | 取值 |
|---|---|---|
| 明度 | 抽 3 帧看直方图 | 暗 / 中 / 亮 / 高反差 |
| 主色温度 | 取最饱和的 10% 像素算色相 | 暖 / 冷 / 中性 / 霓虹 |
| 材质 | 看纹理和边缘 | 纸 / 布木 / 金属玻璃 / 实拍人像 / 数字 |
| 光向 | 看阴影方向 | 逆光 / 侧光 / 顶光 / 无明确光源 |
| 画面密度 | 主体占面积 | 疏（<30%）/ 密（>60%） |
| 镜头运动 | 全片抽看 | 静 / 缓推 / 手持 / 快切 |
| 年代语境 | 造型与用色 | 当代 / 复古 / 国风 / 未来 |
| 情绪温度 | 一句话概括 | 暖 / 冷 / 锐 / 丧 |

### 第二步：给十二套配方打分

每套配方对这八个特征都有一段"适配区间"。逐项算匹配度（命中 1、勉强 0.5、不匹配 0），
加权求和（明度 0.20、材质 0.18、情绪 0.16、主色 0.14、光向 0.12、密度 0.08、运动 0.06、年代 0.06）。

```bash
python scripts/subtitle_router.py --profile out/sub_profile.json
```

输出排名 + 每套的命中理由。**取 top2，分别排一句样张，让用户选。**
这和分镜打分的逻辑是同一套（见 `02-scoring.md`），只是对象换成了字幕。

### 第三步：在一套配方上做微调

配方给的是骨架，还要按这部片调三个数：

- **字号**：10 字以上的行降一档，6 字以下升一档（同片内允许变）
- **强调色**：从画面主色里取一个，不要另起炉灶
- **入场速度**：快歌 90–120ms/字，慢歌 160–220ms/字

## 四、别忘了：一部片里要有变奏

**主样式是骨架，变奏是呼吸。** 全片一条样式到底，观众三分钟后就不看了；
每句都换样式，又变成杂耍。正确做法是：

| 位置 | 变奏方式 | 幅度 |
|---|---|---|
| 主歌 | 主样式 | — |
| 预副歌 | 字号 +1 档，入场加快 20% | 小 |
| **副歌** | 换**载体**或**分离手段**（例如纸卡→无卡发光） | 中，每片 1–2 次 |
| 桥段 | 去掉载体，只留字（留白） | 大，全片 1 次 |
| 尾句 | 字号 −1 档，慢慢淡出，不回弹 | 小 |

**骨架不能动**：字体、字形、有没有描边的逻辑必须一致。变的只能是载体、字号、速度、强调色。

## 五、执行：参数落到哪

七维度 → ASS 字段的对应关系：

| 维度 | ASS 字段 |
|---|---|
| 载体 | `BorderStyle`（1=无 / 3=色块）+ 自绘路径 `\p1` |
| 字形 | `Fontname`（`assets/fonts/` 里选） |
| 字色 | `PrimaryColour`、`\1c`、`\3c` |
| 分离 | `Outline`（描边）、`Shadow`（投影）、`\blur`（辉光） |
| 动效 | `\fad`、`\move`、`\t`、逐字事件 |
| 排布 | `\an`、`\pos`、`\fsp`（字距） |
| 关系 | 上面几项的组合，没有单独字段 |

两套脚本各管一类：
- `make_subs.py`：**有载体**的（01/05/09/10 纸卡、标签、胶带、磨砂条）
- `make_subs_glow.py --recipe …`：**无载体**的八套已内置（02/03/04/06/07/08/11/12），
  一行参数换一套样式，落位仍由 `lines.json` 决定

## 六、验收（四条，缺一条就不算过）

1. **375px 自检**：缩到手机尺寸，单字 ≥14px，还认得出
2. **亮暗各抽两帧**：亮处不糊、暗处不脏
3. **去色测试**：把主色去掉只看字形和排布，仍然有辨识度
4. **情绪对位**：副歌那几句的字幕，是不是比主歌"重"一点（不是更大，是更亮/更实）

第 3 条最狠也最有用。很多"看起来还行"的字幕，去掉颜色就变成默认字体加白字——
那说明它没有设计，只有滤镜。

## 七、常见错法

| 错法 | 症状 | 改法 |
|---|---|---|
| 全片一套不换 | 三分钟后观众不再看字幕 | 按第四节的变奏表，至少做 2 处 |
| 每句换一套 | 像综艺花字，吵 | 变奏只动载体/字号/速度，字体不动 |
| 载体和画面无关 | 手账片出现金属铭牌 | 载体必须属于这个世界的材质 |
| 亮处硬用发光字 | 糊成一片 | 加柔影（按局部 85 分位，不是整行平均） |
| 暗处硬用纸卡 | 像贴便利贴 | 换无卡族，或把卡片压到 40% 不透明度 |
| 强调色另起炉灶 | 字幕和画面两套色 | 强调色从画面主色里取 |
| 只做一层分离 | 亮处读不出 | 暗底靠描边、亮底靠柔影，两种都要有 |
