# 字幕配方库（十二套）

每套配方 = `05-subtitles.md` 第二节那七个维度的一组取值 + 可直接落地的 ASS 参数。
**字号一律按 1080p 画布写**，换分辨率按比例乘。

选配方的程序写在 `05-subtitles.md` 第三节；这里是配方本身。
`scripts/subtitle_router.py` 里存着同样一份"适配区间"，用来算匹配度。

**调用**（无载体的 8 套已经做进脚本，直接 `--recipe`）：

```bash
# 02 03 04 06 07 08 11 12
python scripts/make_subs_glow.py --lines out/lines.json --out out/subs.ass \
    --sheet "images/s%02d.png" --recipe 04-neon-bleed

# 01 05 09 10（有载体）走 make_subs.py，参数在各自的卡片样式里
python scripts/make_subs.py --lines out/lines.json --beats out/beats.json --out out/subs.ass
```

`--recipe` 只改**样式维度**（字色/描边/辉光/字距/投影/上浮量），
落位仍由 `lines.json` 的 `x/y/fs` 决定——位置是逐句算出来的，不该由配方固定。

## 01 手账纸卡 · `paper-card`

撕边米卡承字，投影代替描边，像从本子上撕下来贴上去的。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 撕边米卡 / 宋 / 暖墨 `#241E1A` |
| 分离 / 动效 / 排布 | 卡片投影（无描边）/ 逐字弹入 + 微旋 / 底部中轴 |

```
BorderStyle=3   Outline=0.24×fs   Shadow=0   卡色 #F3E8D1
每字 \frz ±2.8°  上下错落 ±6px  负字距 −6px
入场 \fad(80,0) + \move(y+6,y,0,120) + \t(0,120,\fscx106\fscy106)
```
**适配**：亮 / 暖 / 纸 / 侧光 / 疏 / 缓推 / 当代 / 暖
**风险**：暗调画面里像贴便利贴——亮度低于 0.35 就别用。

## 02 窗光透字 · `window-glow`

没有卡片，字像被纸后面的灯点亮。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 宋 / 暖米 `#F2E2C4`（重音琥珀 `#EFB05E`） |
| 分离 / 动效 / 排布 | 近黑细描边 + 同色辉光 + 亮处柔影 / 逐字点亮上浮 / 底部中轴 |

```
BorderStyle=1  Outline=0.030×fs  OutlineColour=#0A0D14
辉光层：同字 \blur=0.13×fs  \1c=琥珀  \alpha=68（重音 52）
实字层：\bord=0.030×fs \shad=2（同描边色）
入场 \move(y+8,y,0,210) + \fad(110,200)
柔影：局部亮度>0.16 时按 (lum−0.16)×1.05 递增，\blur=46，上限 0.46
```
**适配**：暗 / 暖 / 纸 / 逆光 / 疏 / 静 / 当代 / 丧
**风险**：亮处必须补柔影，否则整句消失。柔影要按**字幕实际占位**的 85 分位算，不能整行平均。

## 03 碑刻沉字 · `stone-carve`

厚重、慢、字距大，像凿在石头上。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 宋（重字重）/ 石白 `#E8E2D6` |
| 分离 / 动效 / 排布 | 深描边 + 微内阴影 / 慢上浮 400ms / 居中偏下 0.62H |

```
BorderStyle=1  Outline=0.045×fs  #14120F  Shadow=3
Spacing=0.12×fs   字距拉到极限
入场 \fad(400,300) + \move(y+10,y,0,500)
```
**适配**：中 / 冷 / 实拍或石质 / 侧光 / 密 / 静 / 复古 / 冷
**风险**：纸雕/绘本画面里显得过重，会压掉轻盈感。

## 04 霓虹溢光 · `neon-bleed`

两层辉光叠出"灯管溢色"，字本身偏细。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 细黑 / 取镜头霓虹色（洋红 `#D86088` 或青 `#5CB0C8`） |
| 分离 / 动效 / 排布 | 双层辉光（0.20fs + 0.06fs）/ 轻微抖动入场 / 贴底 0.78H |

```
BorderStyle=1  Outline=0.02×fs（同色更亮一档）
远辉光 \blur=0.20×fs \alpha=90   近辉光 \blur=0.06×fs \alpha=60
入场 \t(0,90,\fsp2) + \fad(60,120)
```
**适配**：暗 / 霓虹 / 金属玻璃 / 无明确光源 / 密 / 手持快切 / 当代 / 锐
**风险**：暖调、纸质画面里像 KTV 字幕。

## 05 胶片字幕条 · `film-sub`

最不抢戏的一套：一条半透明深灰，左边距对齐。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 半透明条（`BorderStyle=3`，深灰 55%）/ 无衬线 / `#F0EDE6` |
| 分离 / 动效 / 排布 | 无描边（条就是分离）/ 硬切 60ms / 底部 0.86H 左对齐 |

```
BorderStyle=3  Outline=0.10×fs（条的内边距）  Shadow=0
条色 #0C0E12 alpha 55%
左对齐：\an1 \pos(0.08W, 0.86H)
入场 \fad(60,120)，不加任何位移
```
**适配**：中 / 中性 / 实拍人像 / 侧光 / 密 / 手持 / 当代 / 冷
**风险**：条太宽会吃掉画面下缘；控制在文字宽 + 2 个字。

## 06 铅笔手写 · `pencil-hand`

像有人在画面边上随手记，句子长短不齐。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 手写体 / 石墨 `#2B2B2B` |
| 分离 / 动效 / 排布 | 1px 纸色描边 / 逐字"写出来" / 偏侧 0.32W |

```
BorderStyle=1  Outline=1.2  #F3EDE2（纸色，不是黑）
逐字 \fad(0→255, 90ms) + \t(0,90,\fscx92\fscy92,\fscx100\fscy100)
每字 y 错落 ±6px，角度 ±1.5°
```
**适配**：亮 / 暖 / 纸 / 侧光 / 疏 / 静 / 复古或当代 / 暖
**风险**：手写体小字号必糊，fs < 54 别用。

## 07 金属压印 · `metal-stamp`

上下各一道亮暗边，做出压进金属板的感觉。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 粗黑 / `#C9C4BA` |
| 分离 / 动效 / 排布 | 双色边（上亮下暗）/ 硬切 / 居中 0.5H |

```
BorderStyle=1  Outline=0  Shadow=0
亮边：同字 \pos(y−2px) \1c=#6E6A62 \bord=1
暗边：同字 \pos(y+2px) \1c=#3A3730 \bord=1
主体：\1c=#C9C4BA \bord=0.5
入场 \fad(80,120) 无位移
```
**适配**：中 / 冷 / 金属玻璃 / 顶光 / 密 / 静 / 未来 / 锐
**风险**：暖调片里像游戏 UI；纸雕片里像镀了层假金属。

## 08 水墨题跋 · `ink-colophon`

竖排、右置、墨色带浓淡，像画上的题字。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 宋细 / 墨 `#1C1A17` |
| 分离 / 动效 / 排布 | 无描边（靠 alpha 0.88）/ 淡入 500ms 无位移 / 竖排右置 0.82W |

```
BorderStyle=1  Outline=0  Shadow=0   \alpha=88
竖排：逐字 \an5 排列，字距 0.06×fs，整列居中于 x=0.82W
入场 \fad(500,500)
```
**适配**：亮或中 / 暖或中性 / 纸 / 侧光 / 疏 / 静 / 国风 / 冷
**风险**：横构图里贴右会被裁；右侧 15% 内不能有主体。

## 09 拼贴撕纸 · `collage-torn`

每个字一张小色纸，颜色错落，像剪贴簿。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 多色撕纸卡（低饱和 4 色轮换）/ 黑体 / `#16130F` |
| 分离 / 动效 / 排布 | 硬投影 3px / 弹入 + 旋转 / 居中单行 |

```
BorderStyle=3  Outline=0.22×fs  Shadow=0
色卡池：#E8D3B0 #D9C2C0 #C9D3C6 #E3C9A0
每字 \frz ±4°  上下 ±8px  \t(0,140,\fscx112\fscy112,\fscx100\fscy100)
```
**适配**：亮 / 暖 / 纸 / 侧光 / 疏 / 快切 / 复古 / 暖
**风险**：超过 8 个字就花成一团；副歌长句别用。

## 10 磨砂玻璃条 · `frosted-bar`

一条半透明的磨砂带，字浮在上面。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 磨砂条（灰白 22%）/ 细黑 / `#FFFFFF` |
| 分离 / 动效 / 排布 | 无描边 / 硬切 / 底部 0.90H 居中 |

```
BorderStyle=3  Outline=0.16×fs  Shadow=0
条色 #D8D8D8 alpha 22%（libass 做不了真模糊，用低 alpha 模拟）
入场 \fad(100,180)
```
**适配**：中 / 中性 / 金属玻璃 / 无明确光源 / 密 / 静 / 未来 / 冷
**风险**：暗场里显得脏（半透明灰在暗底上发灰）。

## 11 追光舞台 · `spotlight`

字后面有一团暖白光晕，像被追灯照着。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 椭圆光晕（自绘 \p1）/ 圆体或黑体 / `#FFF3D6` |
| 分离 / 动效 / 排布 | 光晕代替描边 / 脉冲 / 居中 0.45H |

```
光晕：\p1 椭圆，\blur=60，\1c=#FFF0D0，\alpha=40，宽度 = 字宽 × 1.5
主体：\bord=1  \1c=#FFF3D6
入场 \fad(200,300) + \t(0,200,\fscx102\fscy102)
```
**适配**：暗 / 暖 / 实拍人像 / 逆光 / 疏 / 手持 / 当代 / 暖
**风险**：光晕会盖住主体轮廓；主体在中央时别用。

## 12 数据等宽 · `mono-data`

像屏幕上的终端输出，逐字敲出来，带一个光标。

| 维度 | 取值 |
|---|---|
| 载体 / 字形 / 字色 | 无 / 等宽 / `#9BE8C8` |
| 分离 / 动效 / 排布 | 无描边 / 打字机 + 光标 / 左下 0.12W, 0.86H 左对齐 |

```
BorderStyle=1  Outline=0  Shadow=0
逐字事件：间隔 = 句长/字数，每个字 \fad(0,0) + 单独出现
光标：句末加 "▌"，\t(0,400,\alpha&HFF&) 循环闪
```
**适配**：暗 / 冷 / 数字或金属玻璃 / 无明确光源 / 密 / 静 / 未来 / 锐
**风险**：中文等宽字体少，中英混排会跳字距；纯中文句子慎用。
