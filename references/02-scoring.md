# 打分机制：三选一，而不是生一个

**这条流水线的核心不是"会写提示词"，是"写完知道哪个好"。**
同一个镜头写三条提示词，出来差别可能是一个能爆、一个平平、一个根本出不了图。
所以每一层都必须有候选、有评分、有淘汰——**先做多，再做少**。

打分分三层，从粗到细，逐层收敛：

| 层 | 对象 | 候选数 | 产出 | 什么时候做 |
|---|---|---|---|---|
| **L1 风格** | 视觉风格（整套语言） | **5**（不同家族） | 1 套（★推荐给用户选） | 拿到素材、分析完之后 |
| **L2 剧情** | 整支片子的分镜方案 | 3 套 | 1 套（top2 的分镜留作替补） | 风格确认之后 |
| **L3 分镜** | 单镜的场景图提示词 / 视频运动提示词 | 每镜 2–3 条 | 每镜 1 主 + 1 备 | 剧情定稿之后、批量生成之前 |

> **为什么顺序不能反**：风格决定材质和光，剧情决定分镜，分镜提示词必须长在这两者之上。
> 先写提示词再定风格，等于先砌墙再画图纸。

---

## 一、评分卡

每种候选都用 0–5 分（允许 0.5）。**必须写一句"证据"**，只给数字的打分不算数。

### L1 风格卡（5 选 1）

> 打分结果要换算成 ★1–5 给用户看：≥4.5 ★★★★★、4.0–4.4 ★★★★、3.5–3.9 ★★★、3.0–3.4 ★★。
> **第一名必须标出来**，并且附上代价（重试率 / credits）——用户要在有依据的建议上做选择。

| 维度 | 权重 | 5 分是什么样 | 1 分是什么样 |
|---|---|---|---|
| 情绪匹配 | 0.30 | 风格的气质和歌的情绪是同一个词 | 气质打架（丧的歌配糖果色） |
| 素材匹配 | 0.20 | 和用户给的参考视频/歌词意象同族 | 完全无关 |
| 出图稳定性 | 0.20 | 材质简单、主体单一，模型很容易画对 | 依赖多人/手部/文字，十条废六条 |
| 差异化 | 0.15 | 同类内容里没见过 | 一眼就是模板 |
| 节奏契合 | 0.15 | 风格的镜头长度/运镜和 BPM 合得上 | 慢风格配快歌 |

### L2 剧情卡（3 套选 1）

| 维度 | 权重 | 判据 |
|---|---|---|
| **钩子** | 0.20 | 前 3 秒有没有"反常 / 悬念 / 强对比"。竖屏信息流里，前 3 秒决定 70% 的完播 |
| **歌词咬合** | 0.20 | 每个记忆点歌词是否有**具体动作或物件**对应，不是配一张风景 |
| **可生成性** | 0.15 | 分镜里有多少镜踩红线（见第三节），踩一条扣 0.5 |
| **情绪曲线** | 0.15 | 主歌压、预副歌起、副歌爆、尾奏落；有没有"第二段比第一段更强" |
| **风格纯度** | 0.10 | 全片是否同一套材质/光，不会一会儿纸雕一会儿写实 |
| **差异化** | 0.10 | 有没有一个别人不会想到的画面（本片是"城市高楼长出纸根"） |
| **可剪辑性** | 0.10 | 相邻两镜能不能硬切/叠化，空间逻辑是否连贯 |

### L3 分镜卡（每镜 2–3 条选 1）

| 维度 | 权重 | 判据 |
|---|---|---|
| **主体明确** | 0.20 | 一句话能说清画的是什么，没有"两个东西抢戏" |
| **可生成性** | 0.20 | 同上，踩红线直接扣 |
| **歌词对位** | 0.15 | 这一镜的动作/物件是否正好落在这句歌词的重音上 |
| **构图可读** | 0.15 | 缩到 375px 还认得出主体；主体不贴边、不被切 |
| **光与色** | 0.15 | 有没有明确光源方向和冷暖关系（没有光的提示词出图一定平） |
| **前后对比** | 0.15 | 和上一镜的景别/色温/构图有明显差别，不然剪起来像卡住 |

## 二、打分纪律（不做这四条，打分就是走过场）

1. **同一轮候选由同一个"评委"打分**。写了三条提示词，就一次性把三条都评完，不要写完一条评一条——标准会漂。
2. **证据先行**：每个分数后面跟一句为什么。写完发现写不出理由，说明这个分是编的。
3. **不许全员 5 分**。一轮里至少有一项 ≤3，才说明真的在挑。全 5 分等于没评。
4. **分数只用来排序，不用来"及格"**。真正的门槛是"能不能出片"，不是 4.2 这个数字。

## 三、可生成性红线（feasibility 的直接扣分项）

这些是这个 skill 里反复踩出来的，不是理论：

| 红线 | 扣分 | 为什么 |
|---|---|---|
| 手部特写 / 手指数量可见 | **−1.5** | 纸雕手最容易崩，五根手指变七根 |
| 画面内出现文字（除片头/封面） | **−2.0** | 中文必错，还会自己加平台 logo、二维码 |
| 三人以上同框互动 | −1.0 | 站位和朝向会乱，剪起来接不上 |
| 精细机械 / 乐器 | −1.0 | 弦、键、齿轮会糊成一团 |
| 镜面 / 水面清晰倒影 | −0.5 | 倒影和本体对不上 |
| 复杂透视（仰拍建筑、鱼眼） | −0.5 | 层与层会穿模 |
| 特定品牌 / IP / 明星脸 | −2.0 | 直接违规或被拒 |

> 一条提示词踩两条红线，基本就该换方案，不用再算总分。

## 四、淘汰赛怎么打（最多三轮）

```
第 1 轮 · 粗筛
  所有候选按总分排序，< 3.0 直接淘汰，剩下的进复赛
第 2 轮 · 定向改写
  取 top2，各自找"最低分的那一维"，只改这一维，重写一版再评
  （改完通常能涨 0.3–0.8；改不动说明方向错了，换方案）
第 3 轮 · 定稿
  分差 > 0.3 → 高者胜
  分差 ≤ 0.3 → 按"可生成性"决胜：能出片的赢，好看的输
```

**为什么最后一轮不比总分**：两条提示词差 0.2 分，观感上没区别；但一个能一次出图、
一个要重试五次，成本差 5 倍。**能出片 > 好看一点点。**

**备选要留**：每镜的 top2 都存进 `out/score.json`。某一镜生成失败（跑偏、主角不对、有字），
直接换备选，不用重新想。

## 五、落盘格式

```json
{
  "version": 1,
  "song": "无人知晓的我",
  "style": {"winner": "paper-night", "score": 4.35, "runner_up": "paper-dawn"},
  "script": {
    "winner": "B",
    "score": 4.10,
    "candidates": [
      {"id": "A", "score": 3.55, "evidence": "钩子弱：前 3 秒是空镜"},
      {"id": "B", "score": 4.10, "evidence": "钩子强：第一镜纸城全景立刻压字"},
      {"id": "C", "score": 3.80, "evidence": "情绪曲线平，副歌没有升级"}
    ]
  },
  "shots": [
    {
      "id": "s08",
      "winner": "b",
      "score": 4.25,
      "candidates": [
        {"id": "a", "score": 3.60, "red_lines": ["hand_closeup"],
         "evidence": "手部特写，纸雕手会崩"},
        {"id": "b", "score": 4.25, "red_lines": [],
         "evidence": "陀螺+灯带，主体单一、光源明确"},
        {"id": "c", "score": 3.90, "red_lines": [],
         "evidence": "构图够，但和 s07 都是俯拍，剪起来像重复"}
      ]
    }
  ]
}
```

`score_candidates.py` 读这个文件，算加权总分、排序、标红踩红线的候选、给出淘汰建议：

```bash
python scripts/score_candidates.py out/score.json --layer shot
python scripts/score_candidates.py out/score.json --layer script --json
```

脚本只做算术和规则校验，**判断由你做**。它能拦住的错误有三类：
权重加错、漏写证据、踩红线还给了高分。

## 六、一个真实的打分过程（本片第 8 镜）

歌词：「固执的自转陀螺」。

| 候选 | 提示词核心 | 主体 | 可生成 | 对位 | 构图 | 光 | 对比 | 总分 |
|---|---|---|---|---|---|---|---|---|
| a | 一只手拧动陀螺的近景 | 4 | 2（手部红线） | 5 | 4 | 4 | 4 | **3.55** |
| b | 陀螺在纸台面上高速旋转，一束顶光，背景全黑 | 5 | 4.5 | 5 | 4.5 | 4.5 | 4 | **4.55** |
| c | 俯拍陀螺与一圈小纸人围观 | 3（抢戏） | 3（多人） | 4 | 4 | 4 | 4 | **3.70** |

b 胜出。a 输在手部红线——**不是不好看，是做不出来**。
这就是这套打分真正的作用：它挡住的不是平庸，是"看起来很好但一定翻车"的方案。

## 七、什么时候可以不这么麻烦

- **单镜短片（<30 秒）**：L2 可以省，但 L3 不能省。
- **用户已经给了明确风格 + 参考视频**：L1 可以省，直接按参考走。
- **换镜（只重做一两镜）**：只跑 L3。

除此之外，三层都要走。**省掉的每一层，最后都会以"重做整片"的形式还回来。**
