# 封面：成片之后那一步

视频渲完、质检过了，还没结束——**发布时平台展示的是封面，不是第一帧**。
一条三分钟的片子，信息流里只有一张缩略图决定有没有人点。

本文件只管"从成片到一张能发的封面"。出图用 ImageGen，排版用 `scripts/make_cover.py`。

---

## 一、先搞清平台要什么比例

| 平台 / 位置 | 比例 | 尺寸 | 说明 |
|---|---|---|---|
| **抖音 / 快手 / 视频号 · 全屏竖版** | **9:16** | **1080×1920** | **默认。占屏最大，观感和留人率都更好** |
| 抖音 · 信息流缩略图 | 3:4 | 1080×1440 | 部分位置仍按 3:4 裁；9:16 会裁成中间一段 |
| 小红书 · 笔记封面 | 3:4 | 1080×1440 | 竖版笔记吃 3:4 |
| B 站 / YouTube 横版 | 16:9 | 1920×1080 | 横版平台的场景 |
| 头像 / 方形位 | 1:1 | 1080×1080 | 少数分发位 |

**默认做 9:16**（用户 2026-10-23 实测反馈：竖版观感更好、留人率更高）。
同时出一版 3:4 备用，因为同一条片的分发位不总是同一个比例。

**9:16 的排版要点**（和 3:4 不同，别直接把 3:4 拉长）：

- 标题占宽 **72–85%**（比 3:4 的 55–65% 更大，因为占屏更高、离眼睛更远）
- 标题放在**三个位置之一**：上（0.20–0.26H，天空/暗部）、中（0.28–0.34H）、下（0.78–0.84H，压暗区）
- 底部 12% 不放关键信息（平台 UI 会盖）
- 竖版**不要**把标题塞进一条横带里——横带在 9:16 上会显得又扁又小

## 一·五、横版作品：个人页网格会把它裁成 3:4

**这是发布后才发现、而且很难补救的一类问题。**

抖音的「个人页 / 双列布局」网格是 **3:4**。你的视频是 16:9 时，如果没单独上传封面，
平台会拿视频首帧**居中裁成 3:4**——1920×1080 只剩中间 810 宽，**切掉 58%**。
标题横跨整幅的封面，两边的字直接被切掉，主页看起来就是乱的。

| | 信息流 | 个人页网格 |
|---|---|---|
| 展示比例 | 16:9 / 9:16（跟随视频） | **3:4（固定）** |
| 16:9 封面会发生什么 | 完整显示 | **居中裁掉两侧 58%** |

### 结论：横版作品必须单独上传一张 3:4 封面

发布页 →「设置封面」→ 上传自定义图（1080×1440）。**不要让平台拿首帧自动裁。**

### 两种做法（保住整个 16:9 画面）

**A 模糊延展**：16:9 画面满宽放在 3:4 画布中间，上下的空档用同图的模糊 + 压暗补满，
标题压在下方的模糊带里。像电影海报。

**B 纸卡明信片**：16:9 画面像一张照片贴在米色纸上，四周留白，标题印在纸面下方。
最像"出版物"，主页网格里最整齐。

两个都有现成脚本，一条命令出图（自动检并裁掉平台水印）：

```bash
python scripts/make_poster34.py --src images/s02.png --out cover/p1.png     --title "无人知晓的我" --artist "A-Lin · 纸雕 MV" --style postcard

python scripts/make_poster34.py --src images/s02.png --out cover/p2.png     --title "无人知晓的我" --artist "A-Lin" --style blur
```

`--style postcard|blur`，默认 postcard；产物自动带 `_1280.jpg` 与 `_chk375.png`。

```
画布      1080×1440
照片区    宽 972（左右各留 54），高按 16:9 算 ≈547，上边距 150
标题      照片下方 96px，字号 96，暖墨 #2B2118
细线      标题下 70px，宽 240，砖红 150 透明
署名      细线下 40px，字号 30
```

### 安全区（两种做法都适用）

- 标题放在**中间 70% 宽**以内——即使平台再裁一次也不会断字
- 底部 **12%** 不放关键信息（评论区、按钮会盖）
- 主体（人脸/动作）别贴左右边缘 15%

### 系列一致性

主页网格好不好看，**靠的是"每张都长一样"，不是"每张都好看"**：

- 一部片只用一种做法（模糊 **或** 明信片），不要混
- 字体、字号、标题位置、细线长度全部固定
- 风格色可以随片子变，版式不能变

## 二、三条硬规矩

### 1. 标题优先让 ImageGen 直接画出来，但要逐字核对

**默认走 ImageGen 直出**（用户 2026-10-22 明确要求）。理由不只是省事：字画进画面后，
它会跟着纸的褶皱、透视和背光一起变，后期合成永远做不到这一步——合成字是平的、干净的、
和纸不在同一张皮上。

**实测边界**（这个结论是踩出来的，不是猜的）：

| 文本形态 | 直出成功率 | 说明 |
|---|---|---|
| 6 字以内的**单列大字**标题 | **高** | 《无人知晓的我》竖排 6 字 + `A-LIN`，一次全对 |
| 3–5 字的横排大字 | 较高 | 形近字仍可能串（伦/论） |
| 两行以上 / 多段小字 / 正文 | 低 | 小字必糊，繁简混用，会臆造不存在的字 |

所以规则不是"能不能用模型"，而是**用完之后必须核对**。核对清单见第四节。

**什么时候退回字库合成**：小字多、有多行副标、需要精确对齐、或者连试两次都错字。
合成脚本 `make_cover.py` 保留着，走的是另一条路：

```
ImageGen 出「完全无字」的底图  →  make_cover.py 用字库排标题
```

底图提示词的正向和反向都要写死无字：

```
... no typography, no words, no text, no letters, no Chinese characters,
no signage, no logo, no watermark
```

### 2. 字要留出"呼吸"——首字不能顶到载体边缘

这是直出最容易翻车的地方（合成版也踩过：字号按载体高度算满，`无` 直接顶到幡的边）。
提示词里必须写死三件事：

- **顺序点名每个字**：`exactly six characters in this order from top to bottom: 无 人 知 晓 的 我`
- **要大字**：`in large warm-black Chinese serif characters`
- **留白**：`with generous EMPTY paper margin above the first character and below the last one`
- **署名小字**：`underneath, in much smaller letters: A-LIN`
- **封口**：`no other text, no letters, no numbers, no logo, no watermark anywhere else`

少写"留白"这一条，模型就会把字撑满整张纸。

### 3. 文字必须站中间、有载体（这是版式的第一原则）

用户 2026-10-22 明确的标准，按优先级：

| 层级 | 落点 | 判定 | 位置 |
|---|---|---|---|
| **① 标准（默认）** | **画面里的实体**：纸幡、招牌、信纸、信封、票根 | 只要画面里有能承载字的实物，就用它 | **文字块在画面水平正中**，垂直重心 42–50% |
| ② 次选 | 纯负空间（夜空、雾、暗部） | 没有载体，但有一片真正净空 | 文字落在净空里，主体在下 |
| ③ 最后 | 底部纸带 | 既没载体也没净空 | 纸带压底，横排 |

**为什么载体是第一选择**：字长在实物上，就和纸的褶皱、透视、背光一起变，观感是"这块纸本来就写着字"。
推到画面顶部或底部的横排标题，读起来永远是"后来贴上去的"。

**为什么必须居中**：封面在信息流里是缩略图，视线只会落在正中那一小块。
文字偏上偏下，缩略图上就变成一条边角信息，观众不会把它当标题。

具体数值（标准版式）：

- 载体占画面宽 **30–42%**、高 **55–70%**，自身**水平居中**
- 字块中心 = 载体中线（±8px）= 画面中线（±8% 画面宽）
- 标题占载体宽/高 **60–75%**，上下留白 ≥ **6.5%**
- 署名 = 标题 × **0.33**，与标题同轴，压在标题下方

> **最忌讳**两种：① 一块纯白/纯色的大卡片（和画面没有材质关系）；
> ② 把标题推到画面四角或顶部（B/C 那种横排位），除非画面里**根本没有可用载体**。

**例外**：画面是纯空镜（天空、水面、雾）时，没有实体可承载，才退到 ②；
信息量大（要放副标、时长）才退到 ③。两者都是退路，不是并列选项。

## 三、出底图

### 3.1 直出带字（默认路线）

```
Vertical 3:4 poster image, handcrafted paper-cut diorama of <场景>.
A tall vertical banner of torn handmade cream paper hangs from a thin brass rod
in the centre, softly glowing warm amber from a light behind it, deckle edges rim-lit.
Printed vertically down the centre of the banner, in large warm-black Chinese serif
characters, exactly six characters in this order from top to bottom: 无人知晓的我.
The text block sits in the middle of the banner with generous EMPTY paper margin
above the first character and below the last one.
Underneath, in much smaller letters, the artist name: A-LIN.
<环境：两侧纸楼、湿纸街道、暖窗、尘埃>
No other text, no letters, no numbers, no logo, no watermark anywhere else in the frame.
```

四个必写项：**逐字点名顺序** / **large serif** / **首字上方与末字下方留白** / **no other text**。
`no other text` 要写在最后一句，模型对句末约束更敏感。

### 3.2 无字底图（合成路线，保底）

```
macro photograph of a handcrafted paper-cut diorama, vertical 3:4 portrait
composition, <场景>, <主体与光源>, <留给标题的载体或负空间>,
deep indigo night palette, dust motes, shallow depth of field,
absolutely no text, no letters, no characters, no writing, no signage,
no logo, no watermark
```

三条关键短语，缺一个就会出问题：

- `vertical 3:4 portrait composition` —— 不写就给你 16:9
- `<载体> is COMPLETELY BLANK and empty` —— 不写它会在招牌上自己加字
- `absolutely no text ... no watermark` —— 正反向都要

### 水印照旧要裁

ImageGen 在**右下角**打「AI生成 WorkBuddy」。3:4 出图是 1024×1536，
水印落在 y≈1476–1526，所以**裁 1024×1365（正好 3:4）就能整块切掉**，再放大到 1080×1440：

```python
im.crop((0, 0, 1024, 1365)).resize((1080, 1440), Image.LANCZOS)
```

`make_cover.py` 的 `fit_image()` 只做居中裁切，不认水印，
所以**底图要先自己裁好**，脚本只负责排版和出图。

## 四、直出后的核对清单（必做）

模型能画字，但不能保证每次都画对。**把图放大到 100%，逐条过**：

- [ ] **数一遍字数**：六个字是不是六个？漏字比错字更常见（实测让模型"把字画大"时丢过两个）
- [ ] **逐字读一遍**——形近字（伦/论、课/棵、末/未）和繁简混用最常出问题
- [ ] **首字有没有顶到载体边缘**——这是"字跑出去"的典型症状，宁可重出也别将就
- [ ] **末字与署名之间有没有余量**，署名有没有被压到纸边
- [ ] **署名拼写**：`A-LIN` 里的大小写和连字符最容易糊
- [ ] **画面里有没有多出来的字或物料**：招牌、车牌、副标、"新歌单"、二维码、平台 logo
      ——模型会在边角自己补一整块发行物料，发现就整张重出
- [ ] **文字是否在画面水平正中**（载体居中、字块居中）；偏到一侧就不是这个版式了
- [ ] **水印**是否已裁掉

任何一条不过：改提示词重出一次；第二次还不过，**退回 3.2 + `make_cover.py` 合成**。

## 五、排字（合成路线）

```bash
# 竖排：字排进画面里的纸幡/招牌（--area 是载体在成图坐标系里的范围）
python scripts/make_cover.py --src cover/base_3x4.png \
    --title "无人知晓的我" --artist "A-LIN" \
    --ratio 3:4 --vertical --area 450,478,690,1002 \
    --out cover/封面_v1.png

# 横排 + 底部纸带
python scripts/make_cover.py --src cover/base_3x4.png \
    --title "无人知晓的我" --artist "A-LIN" \
    --ratio 3:4 --layout band --band 0.28 --out cover/封面_v1.png
```

参数：

| 参数 | 作用 |
|---|---|
| `--ratio` | `3:4` / `9:16` / `4:5` / `1:1` / `16:9`，决定成图尺寸 |
| `--layout vertical` | 竖排，字排进 `--area` 指定的载体（最常用的中文竖题） |
| `--layout band` | 横排，底部铺一条从底图中位色取的纸带 |
| `--area x0,y0,x1,y1` | 竖排字块可用区。**必须实测载体位置**，别估 |
| `--band 0.30` | 纸带高度占比 |
| `--band-color auto` | `auto`（暗底自动换米色）/ `sample`（照抄底图色）/ `paper`（强制米色） |
| `--title-width 0.62` | band 模式标题占画面宽的比例 |
| `--anchor top` | 竖图裁切时保留顶部（主体在上半时用） |

### 字怎么压进纸里

脚本的 `press()` 做四件事，少一件就会"像贴上去的"：

1. **纸纹调制**：用底图亮度调制字的不透明度（纸纹处墨略淡）
2. **压印阴影**：向下 2px 偏移、35% 强度的暗层
3. **轻微模糊**：0.45–0.6px，去掉矢量锐边
4. **暖墨色**：`#2B2118`，不要纯黑（纯黑像贴纸）

### 字号

- 竖排：`fs = area_h / (n + (n-1)*0.06 + reserve)`，有署名时 `reserve≈0.55`
- 横排：二分找填满 `框宽 × 0.86` 的字号
- 署名 = 标题 × **1/3**（0.33），字距 = 标题的 1/10
- 必须衬线（MV Serif SC），无衬线会像 UI 标签

## 六、自检（合成路线会打印）

| 指标 | 竖排 | 横排 | 不合格的表现 |
|---|---|---|---|
| 占载体 / 占画面 | 占载体高 **75–95%** | 占画面宽 **45–60%** | 太小 = 缩略图上一行小字 |
| 中线 | 标题中心 = 载体中心（±18px） | 标题中心 = 画布中心（±24px） | 一眼看出没对齐 |
| 375px 可读 | 单字 ≥ **14px** | 同左 | 手机上糊成一团 |

脚本同时产出三档：

```
封面_v1.png        # 原尺寸（1080×1440）
封面_v1_1280.jpg   # 上传用（体积小，质量 92）
封面_v1_chk375.png # 手机尺寸自检，必须亲眼看一次
```

## 七、常见坑

1. **拿视频第一帧当封面**。第一帧通常最暗、信息最少。封面要单独出图。
2. **16:9 直接传抖音**。两侧被裁，标题必切。
3. **在封面里写太多字**。缩略图只容得下：歌名 + 歌手。副标、时长、"AI生成"角标都可省。
4. **标题压在主体脸上 / 横穿构图重心**。先看底图的负空间在哪，再定 `--area`。
5. **首字顶到载体边缘**。直出时提示词漏了"留白"；合成时字号按载体高度算满。前者改提示词，
   后者把 `--area` 上下各收 8%，再加 `reserve=0.55` 给署名留位。
6. **合成时把竖排字排到载体外面**。`--area` 一定要用脚本实测（亮度阈值取载体 bbox），不要凭肉眼估——
   估出来的框常常偏左 60–80px，字就跑到纸外面去了。实测办法：
   ```python
   lum = np.asarray(Image.open("base.png").convert("RGB")).mean(2)
   cols = np.where((lum[300:1100] > 140).sum(0) > 120)[0]   # 载体的 x 范围
   ```
7. **暗底图套纸带**。纸带色若照抄底图，会得到"深色带 + 深色字"，糊成一片。
   `--band-color auto` 会在采样亮度 < 0.42 时自动换成米色纸。
8. **字色用纯黑**。在米色纸上像贴纸，用 `#2B2118` 这类暖墨。
9. **忘了 375 自检**。在 1080 上看很爽，到手机上就是一坨。
10. **直出后不核对就直接发**。模型对大字越来越准，但从不保证；一条 375px 缩略图里的错字，
    修起来比重出一次贵得多。
11. **为了"更醒目"让模型把字放大加粗**。实测两次都翻车：
    - 写到 `each character nearly filling the banner width` → **只出了 4 个字**（丢"的我"）
    - 改成 `about half the width` + 明确数数 → 六个字对了，但右侧**自己加了一整块平台物料**
      （"An Unknown Me""遗落天境 新歌单"、二维码、网易云 logo）
    **字数越满，模型越容易丢字或加料**。想要更重的文字，靠"缩小载体让字占比变大"，
    不要靠"催它把字画得更大"。
