# 封面：机械操作清单

> **设计与提示词的唯一依据是 `07b-cover-brief.md`（抖音系列封面标准化生图提示词 V2.0）。**
> 本文件不含任何设计规则——构图、字体、字色、标题位置、比例、质感、禁止项，
> 一律照 07b，这里不再重复，也不另给说法。
> 本文件只回答一件事：**图出来之后怎么处理、怎么导出、怎么验。**

---

## 一、出图

1. **原始图片**：从成片里截一帧作 image1。不要用第一帧（第一帧通常最暗、信息最少）。
2. **提示词**：把 07b 第二节「角色和核心目标」到第六节「内部设计流程与最终输出」原样带入，
   再填好 07b 第一节的 6 个输入项（参考案例 / 原始图片 / 主标题 / 副文案 / 主题关键词 / 画面比例）。
3. **画幅与尺寸**：以 07b 第一节【画面比例】与【目标尺寸】为准（3:4 用 `--size 1024x1536`）。
4. 一次只出一张（07b 第六节：不输出草图与多个方案）。
5. **出图命令**：走第三方网关，不再用内置 ImageGen——

   ```bash
   python scripts/media_api.py image --prompt-file work/cover_prompt.txt \
       --size 1024x1536 --out cover/cover.png
   ```

   需要以成片截帧为底做编辑时，用 `edit` 子命令（`hunyuan-image-alpha-edit`，输入是 data URL）。

---

## 二、水印

**先检测再裁，不要套旧坐标。** 旧内置 ImageGen 在**右下角**打「AI生成 WorkBuddy」，
位置约在底部 62px 内（比例随出图尺寸变）；第三方混元出图的水印位置要重新实测。

- 用 `scripts/crop_watermark.py --only watermark` 先量 bbox，再裁，再复测。

- **等比裁**：先按高度缩放再居中裁宽，**不要直接拉成 3:4**（会变形）。
- 裁完把图放到 100% 看一眼右下角，确认没有残留半截字。

---

## 三、导出

**只出一个文件**：

| 产物 | 规格 |
|---|---|
| `封面_<歌名>.png` | **1200×1600**（3:4），PNG |

不要另出 jpg、不要另出 375 缩略图、不要出多档尺寸。一张就够。

---

## 四、交付前自检

- [ ] 数字数：主标题的字数对不对（漏字比错字常见）
- [ ] 逐字读一遍：形近字、繁简混用
- [ ] 画面里有没有多出来的字与非请物料：招牌、副标、二维码、平台 logo、英文标语
- [ ] 副文案是「无」时，画面上确实没有副文案
- [ ] 右下角水印已裁净
- [ ] 把图缩到 375px 看一眼，主标题与画面核心仍能辨认（临时预览即可，不必存文件）

任何一条不过：按 07b 重出，不要在原图上修。

---

凡是与 `07b-cover-brief.md` 不一致的旧记忆、旧习惯、旧模板、旧脚本参数，一律以 07b 为准。
画幅、比例、尺寸、字体、字色、标题位置、构图、质感、禁止项——全部只在 07b 里找答案。
