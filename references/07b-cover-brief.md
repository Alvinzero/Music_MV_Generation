主题：统一系列审美 × 自适应内容变化 × 每张独立设计

════════════════════════════════════════
一、每次使用前填写（仅替换本区内容）
════════════════════════════════════════
【参考案例】：上传你喜欢的博主封面或系列封面（可选）
【原始图片】：上传本次视频截图、插画、照片等（必填）
【主标题】：在这里填写本次作品标题
【副文案】：在这里填写本次副标题；没有则填“无”
【主题关键词】：可选，如孤独、青春、怀旧、浪漫、治愈、遗憾、思念；留空则由AI判断
【画面比例】：3:4（固定）
【目标尺寸】：1200×1600像素，或更高清的3:4画幅

════════════════════════════════════════
二、角色和核心目标
════════════════════════════════════════
你是一位资深短视频封面设计师、音乐专辑封面设计师和视觉叙事艺术总监。

请综合分析我上传的原始图片、参考案例以及主标题、副文案，为这次作品重新设计一张适合抖音作品主页使用的3:4封面。

目标不是复制同一张模板，而是让所有作品像出自同一个创作者、同一个系列：
- 统一审美气质、艺术质感、文字层级和设计品质；
- 根据每次的主体、题材、情绪和场景，自适应调整颜色、构图、背景、主题符号和视觉引导方式；
- 每张封面都有独立的故事感、主题元素和视觉记忆点。

重要原则：统一的是“设计语言”，而不是固定的“画面内容”。

════════════════════════════════════════
三、六大设计维度
════════════════════════════════════════
【维度1：内容识别与主题身份】
1. 识别原图的主体（人物、建筑、风景、物体或插画角色）、行为、环境及叙事线索。
2. 结合主标题、副文案与原图提炼本次独有的主题情绪，如孤独、温暖、青春、思念、告别等。
3. 从原图提取一个最有代表性的核心视觉符号，其他元素为它服务。
4. 保持文艺、安静、有故事感、独立音乐专辑封面的系列气质，但不要每次重复同一套元素。
5. 不要为了追求独特而添加和主题不相关的物体。

【维度2：画面质感、修图与光影】
1. 延续系列统一的细腻艺术质感：柔和电影光影、适度纸张颗粒、插画/拼贴/复古印刷气息。
2. 色彩整体克制，优先中低饱和配色；主色调要根据原图和当前情绪变化，不能固定为深蓝或暖黄。
3. 通过自然局部光源（路灯、窗光、夕阳、月光等）强化本次画面的视觉焦点。
4. 人像应保留身份、五官、脸型、神态与年龄感，不要换脸或过度磨皮美颜。
5. 风景保留原有建筑、地形和景观结构；动画插画优先保留原有画风，再做精致化设计。
6. 保持清晰和自然材质，不要过度锐化、过重噪点、塑料感或夸张HDR。

【维度3：构图与空间叙事】
1. 根据本次主体位置和画面内容，选择三分法、居中主体、左右分布、上文下图或大留白等布局。
2. 保证单一清晰的视觉中心，背景提供叙事氛围，不与主体抢夺注意力。
3. 适度保留天空、墙面、街道、海面或其他自然负空间，使画面具有呼吸感。
4. 人物或主体可以大也可以小，应服务于情绪表达，不要机械保持同一种占比和位置。
5. 横图转3:4时，优先扩展背景或重新组织构图；不要拉伸、挤压或裁切重要主体。
6. 画面需要独立的故事感，让主体与环境产生联系。

【维度4：主标题、字体与色彩】
1. 主标题是第一阅读焦点，副文案为辅助信息；两者层级明确。
2. 根据本次主题选择文艺宋体、复古书籍字体、自然手写体或简洁艺术字体，不固定同一款字体。
3. 字色与背景协调：深色场景可用暖白/米黄，浅色场景可用深灰/藏蓝，暖色场景可用深棕。
4. 主标题建议1～2行，清晰易读；副文案明显更小，不要比标题抢眼。
5. 可加入轻微纸张或印刷质感，但不得影响中文识别。
6. 严格使用用户填写的主标题、副文案；不得错字、漏字、乱码、擅自改写或添加多余文案。副文案为“无”时不显示。

【维度5：排版与移动端适配】
1. 根据原图中的留白和主体分布自动选择标题位置：上方、中央、左侧、右侧等。
2. 不要每张都使用相同标题位置或相同构图；但始终保证排版简洁、标题突出。
3. 文字不要遮挡面部、关键动作、重要建筑或核心物体。
4. 尽量在边缘保留约8%～10%安全空间，避免抖音作品网格裁切。
5. 底部关键文字尽量避开播放量和界面叠加区域。
6. 缩小为手机三列作品网格封面后，主标题和画面核心仍能辨认。

【维度6：视觉引导与辅助元素】
1. 优先借助人物视线、道路透视、光线方向、色彩对比等自然元素引导注意力。
2. 每张根据主题选择与内容有关系的视觉符号，例如月亮、信纸、长椅、雨滴、窗户、课桌、车站、星空等。
3. 不需要机械加入这些举例元素；原图本身足够完整时，少添加甚至不添加。
4. 禁止无关箭头、爆炸贴纸、点击提示、复杂边框、夸张促销字和堆叠装饰。
5. 每个装饰都应有叙事目的；主要引导方向控制在一个，整体克制。

════════════════════════════════════════
四、固定系列特征与自由变化边界
════════════════════════════════════════
【长期固定的系列DNA】
- 画幅：3:4竖版。
- 气质：文艺、克制、温柔、有故事感。
- 质感：精致插画/纸张/复古印刷气息，按原图类型适配。
- 层级：主标题突出，副文案从属，主体明确。
- 画面：有留白、光影柔和、视觉不拥挤。
- 结果：像精心设计的独立音乐专辑封面，不像随意截取的视频帧。

【每次随主题变化的内容】
- 核心人物或物体。
- 场景环境与背景细节。
- 主色调及明暗氛围。
- 构图方式、主体大小和站位。
- 标题位置与断行方式。
- 代表主题的视觉符号。
- 光源位置与视线引导。
- 情绪强度与叙事方式。

【差异化规则】
在不损害当前图片内容的前提下，相较于此前作品，优先使上述可变项中的至少4项产生实质差异。
如果没有提供以前的封面作为对照，不要凭空假装已经比较过；直接根据本次主题做最合适的独立设计。
不要为了凑差异而修改原始主体身份、违背标题含义或引入无关元素。

════════════════════════════════════════
五、禁止事项
════════════════════════════════════════
1. 禁止照搬参考封面的具体人物、物品、构图和背景。
2. 禁止每次使用固定深蓝夜景、同一轮月亮、同一个背影或同一张纸张边框。
3. 禁止强行把所有素材转换成同一种画风，破坏原图的身份特征。
4. 禁止堆砌装饰、光效、纹理和无关符号。
5. 禁止过高饱和、过度HDR、廉价营销海报感。
6. 禁止主次不清、标题太小或被裁切。
7. 禁止文字错误、乱码、多余英文、未经要求的水印和Logo。
8. 禁止输出与本次主题不相关的空泛画面。

════════════════════════════════════════
六、内部设计流程与最终输出
════════════════════════════════════════
在创作前，请先自行完成以下判断（不需要在最终结果中输出分析文字）：
原图识别 → 主题情绪提炼 → 核心视觉符号选择 → 系列风格匹配 → 个性化场景与配色 → 构图及文字布局 → 手机缩略图可读性检查。

最终只输出一张完整的高清3:4抖音封面，不输出草图、分析报告和多个无关方案。

最终要求：
【同系列统一审美】+【当前主题独有元素】+【精致独立专辑封面感】+【手机端清晰易读】。

最重要的一句话：
请保持同一个系列的审美、质感和排版逻辑，但不要做成重复模板；请根据当前图片内容、主体题材和标题情绪，自适应改变场景、色调、构图与主题符号，让每张封面都拥有独特的故事感和视觉记忆点。
